# 栖息地 · 视觉语言（UI_DESIGN）

> 状态：**骨架待补充**。本文件定义栖息地的视觉语言。
> 工作规则：**在北北补充本文档之前、或未被明确要求时，所有页面一律只做简单 UI 设计**——
> 布局清晰、信息层级明确、Tokens 驱动；不堆砌视觉细节、不做复杂动效、不 1:1 复制任何现有产品。

---

## 1. 设计原则

- 简洁、留白、清晰层级（任务书 §11.3）
- 移动端优先，桌面端兼容
- 圆角、长聊天体验、键盘适配、Safe Area
- 信息层级参照 ChatGPT App 移动端的交互习惯（不 1:1 复制）

## 2. Design Tokens（占位）

- 色彩（深 / 浅两套）、字体、字号阶梯、圆角、间距、阴影、动效时长
- 承载方式：CSS 变量，支持运行时切换与主题方案保存（§11.3）

## 3. 信息层级与排版（占位）

- 页面标题 / 区块标题 / 正文 / 辅助说明 / 时间戳（五级，暂定）

## 4. 核心组件规范（占位）

- 聊天气泡（两种模式：聊天软件式按句切段 / AI 原生式整段显示）
- 时间线分组（今天 / 昨天 / 日期）
- 消息块渲染（text / html / image / audio / file / tool-result / widget）
- 底部导航、卡片、列表项、输入区

## 5. 页面基调（占位）

- Chat / Home / LLM / Life / Setting 五个一级页各自的气质（待补充）

## 6. 动效与微交互（占位）

- 原则：少即是多；Phase 6 之前仅保留必要过渡
