## 2. 风格一句话

**性冷淡留白 + 雨夜玻璃感。** 平时白底黑字、极安静；只有「日记 / 欢迎 / 独处」三个情绪页
才换成深色雨幕 + 玻璃卡。

- 强调色 = **近黑/近白**（浅色 `#111111` / 深色 `#f2f2f2`），不是彩色。绝大多数界面**无强调色**。
- 玻璃（`.glass`）**是例外，不是默认** —— 满屏玻璃会让文本对比度全线下降。
- 颜色只有「三档文字（primary/secondary/tertiary）+ 一个底色 + 一个表面色 + 一条极淡描边」。
  描边是 `rgba(0,0,0,0.06)` 这种「几乎看不见」的细线，靠留白和阴影分层，不靠线框。

## 3. 令牌要点

- **色彩**：`--bg-base` / `--bg-surface(-solid)` / `--bg-subtle`，`--text-primary|secondary|tertiary`，
  `--border-soft`，`--accent-strong` / `--accent-on-strong`，`--success|warning|danger`。
  深色取 `#121212` 一类的**近黑而非纯黑**，浅色取 `#f3f3f5` 一类的**近白而非纯白**（避免高对比刺眼）。
- **圆角阶梯**：`xs 8 / sm 12 / md 16 / lg 24 / xl 32 / pill 999`。
- **阴影**：只有 `--shadow-soft` 与 `--shadow-lift` 两档，都很淡。
- **动效**：`--ease-out: cubic-bezier(.22,1,.36,1)`，时长 `fast 150 / normal 220 / card 300 / emotion 460`。
  `prefers-reduced-motion` 时必须全部关掉（`.rise` / 气泡入场 / 呼吸圆 / 涟漪）。
- **点击区**：`--hit-min: 44px`（底栏、图标按钮、胶囊按钮都按它来）。
- **字体**：`--font-main`（PingFang SC → SF Pro Display → Inter → 微软雅黑）。
- **图标**：32 个线框图标，24×24 网格、线宽 1.7、圆头圆角；**选中态用实心而不是换色**。
  落在 `web/src/components/qixi/Icons.tsx`。

## 4. 关键机制（做后续批次时别踩）

- **翻译层是过渡手段，不是架构。** `theme/tokens.css` 把旧名 `--color-*` 转发到新令牌，
  所以 551 处旧代码**一行没改**就吃到了新配色。后续每批做到哪个页面，就把那个页面的旧名
  顺手换成新名，逐页收敛；全换完后这个文件只剩对照表，可整体删除。
- **子页面滑入 ≠ 假路由。** 设计里 7 个子页面是从右侧滑进来的，但栖息地必须**保留真网址**
  （`/home/diary` 这种）—— 否则刷新、前进后退、加书签全部失效。做法是 `.sub-layer` 只管动画，
  路由照常。**「路由变了 ≠ 页面已渲染」**，验收要等内容。
- **底栏是浮起的胶囊**，不是贴着底部的一条。`--bottom-nav-height` 的占位方式要跟着重算，
  否则内容会被胶囊盖住。
- **一套衣服一次穿完再上墙。** `qixi/components.css` 里现在有若干**暂时没有组件在用**的类
  （`.bottom-nav` / `.chat-inputbar` / `.breath-circle`…），这是刻意的：分 6 批做，
  衣服先整批进衣柜，后面几批直接套，**不要**因为"没人用"就删掉。

## 6. 纪律（每批都要守）

- **门牌号一个不删**：换皮时 `data-testid` 原样保留（验收脚本有 344 处依赖它）。
  靠**页面文案**断言的少数几条要逐个修，不许装作没看见。
- **假数据一律不搬**：原型里的「Rainy Mood, Pt.2」「69 天」「4 篇」都是占位。
  套嵌时全换成真库里的数据；**没数据就显示空态，不许编**。
- **服务端不动**：换装是纯前端的事（只有第 6 批可能碰服务端）。数据、备份格式、接口都不受影响。
- **每批做完** → 验收全绿 + 独立 commit + 停下来汇报（可回退）。
